# MouseNavigation (Minecraft 1.21.4 Fabric)

**MouseNavigation** — легковесный и удобный клиентский мод для **Minecraft 1.21.4 (Fabric)**, добавляющий интуитивную навигацию боковыми кнопками мыши в интерфейсах игры. С ним нижняя боковая кнопка мыши (Mouse 4) работает как «Назад», а верхняя боковая кнопка (Mouse 5) — как «Вперёд», позволяя мгновенно перелистывать книги, переключать вкладки инвентаря и закрывать меню, не затрагивая при этом управление в самой игре.

---

## 🎯 Основная задача мода

Во многих современных приложениях и браузерах боковые кнопки мыши (Mouse 4 и Mouse 5 / Back и Forward) являются стандартом для навигации назад и вперёд. Однако в ванильном Minecraft эти кнопки в интерфейсах не задействованы, и игроку приходится постоянно тянуться к клавише `Esc`, стрелкам клавиатуры или нажимать мелкие экранные кнопки.

**MouseNavigation** решает эту проблему:
- **В любых интерфейсах (меню, инвентарях, контейнерах, книгах, чате)** кнопки мыши отвечают за быстрое перемещение назад и вперёд.
- **В игровом процессе (когда интерфейс закрыт)** мод полностью прозрачен и **не перехватывает клики**: кнопки выполняют ровно те действия, которые игрок назначил в стандартных настройках управления Minecraft.

---

## 🛠️ Что делает MouseNavigation

1. **Кнопка «Назад» (Mouse Button 4 / XBUTTON1 / нижняя боковая)**:
   - **Окна и меню (Настройки, сундуки, инвентарь, пауза, выбор мира и др.)**: мгновенно закрывает экран или возвращает в предыдущее меню (эквивалент клавиши `Esc` / кнопки «Назад» / «Готово»).
   - **Книги и кафедры (`BookScreen`, `LecternScreen`)**: перелистывает на предыдущую страницу (`<`).
   - **Книга рецептов (`RecipeBookWidget`)**: переключает на предыдущую страницу рецептов.
   - **Творческий инвентарь (`CreativeInventoryScreen`)**: переключает на предыдущую вкладку групп предметов.
   - **Экран достижений (`AdvancementsScreen`)**: переключает на предыдущую вкладку достижений.
   - **Чат (`ChatScreen`)**: пролистывает историю отправленных сообщений назад (эквивалент стрелки `↑`).

2. **Кнопка «Вперёд» (Mouse Button 5 / XBUTTON2 / верхняя боковая)**:
   - **Книги и кафедры**: перелистывает на следующую страницу (`>`).
   - **Книга рецептов**: переключает на следующую страницу рецептов.
   - **Творческий инвентарь**: переключает на следующую вкладку групп предметов.
   - **Экран достижений**: переключает на следующую вкладку достижений.
   - **Чат**: пролистывает историю отправленных сообщений вперёд (эквивалент стрелки `↓`).
   - **История экранов**: позволяет вернуться вперёд во вложенный экран, если вы вышли из него кнопкой назад.

3. **Интеграция с ModMenu и гибкая настройка**:
   - В меню модов (**ModMenu**) доступно удобное конфигурационное окно, где можно по отдельности включить или отключить навигацию для каждого типа интерфейсов (книги, чат, вкладки, рецепты, закрытие меню), включить звуковой отклик или инвертировать кнопки.

## 🎮 Таблица поведения

| Интерфейс | Кнопка «Назад» (Mouse 4) | Кнопка «Вперёд» (Mouse 5) |
|---|---|---|
| **Обычные меню и контейнеры** (Настройки, сундуки, верстак, пауза) | Закрыть / Назад (`Esc`) | Возврат вперёд по истории экранов |
| **Книги и кафедры** | Предыдущая страница (`<`) | Следующая страница (`>`) |
| **Книга рецептов** | Предыдущая страница рецептов | Следующая страница рецептов |
| **Творческий инвентарь** | Предыдущая вкладка предметов | Следующая вкладка предметов |
| **Экран достижений** | Предыдущая категория | Следующая категория |
| **Чат** | История сообщений назад (`↑`) | История сообщений вперёд (`↓`) |
| **В игре (интерфейс закрыт)** | Ванильное действие игрока | Ванильное действие игрока |

## ⚙️ Настройки (ModMenu)

При установленном **ModMenu** в настройках мода доступны следующие опции:
- **Общий переключатель**: включение/отключение работы мода.
- **Закрытие меню и экранов**: возврат назад / закрытие контейнеров.
- **Книги и кафедры**: навигация по страницам книг.
- **Книга рецептов**: переключение страниц рецептов.
- **Вкладки креатива**: переключение категорий предметов.
- **Достижения**: переключение вкладок ачивок.
- **История чата**: навигация по ранее отправленным сообщениям.
- **Звуковой отклик**: воспроизведение тихого клика при навигации.
- **Инвертировать кнопки**: поменять местами Mouse 4 и Mouse 5.

Конфигурация сохраняется в файл `.minecraft/config/mousenavigation.json`.

## 📦 Сборка

```bash
gradlew build
```

Готовый файл: `build/libs/MouseNavigation-1.21.4-byMr712.jar`.

## 🚀 Установка

1. Установите **Fabric Loader** (0.16.0+) и **Fabric API** для 1.21.4.
2. Поместите `MouseNavigation-1.21.4-byMr712.jar` в папку `mods/`.
3. *(Опционально)* Установите **ModMenu** для удобного доступа к меню настроек.
4. Запустите игру.
